# Imagens de teste

`lena.jpg` e `messi5.jpg` vêm dos exemplos oficiais do OpenCV:
https://github.com/opencv/opencv/tree/master/samples/data

O teste Full HD também usa `assets/zidane.jpg` instalado com Ultralytics.
São referências temporárias para testar extração, comparação e rejeição de
rostos. Nenhum desses perfis é cadastrado no banco do usuário. O vídeo gerado
usa uma foto com movimento e iluminação simulados; não mede precisão em
filmagens reais da casa.
